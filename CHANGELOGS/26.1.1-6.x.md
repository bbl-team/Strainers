Changelog BBL Strainer

# 6.1.0
- Fixed Clicking on progress arrow in strainer not opening JEI category
- Added missing translations probably still some missing

# 6.0.0
- Updated to Minecraft 26.1.1
- Reduced mesh count to 8 tiers with a single mesh per tier
- Strainers now require a fluid in recipes, this fluid is not consumed but must be present in the strainer not in world
- Recipe now uses a min tier requirement this level is equivalent to the mesh tier tag
- Recipe now has additional_chance_per_tier this is added per additional level above the tier going over 1.0 will guarantee the output and then roles again with remaining chance
