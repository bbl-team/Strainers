Changelog BBL Strainer

# 6.4.0
- Meshes can now be enchanted 
- Efficiency makes the strainer work faster
- Fortune increases drop chances
- Unbreaking increases the chance that the mesh will not lose durability when used
- Meshes can be enchanted in the enchanting table

# 6.3.7
- Mesh recipe now require the previous tier to craft, this helps to balance the mod a little bit more and means players need to craft the meshes in order insteadd of skipping to the best one 

# 6.3.6
- Fixed some recipes being under minecraft namespace instead of strainers

# 6.3.5
- Fixed missing Sapling Bag shift tooltip
- Fixed missing Ancient Debris recipe

# 6.3.4
- Changed some ore piece recipes to come from sand instead of just gravel
- Fixed progress ticking when the strainer output cannot handle the outputs
- Input slots now filtered 

# 6.3.3
- Fixed JEI showing meshes a tier above their minium tier requirement
- Fixed some recipes not working due to input counts being wrong, fixed sand dust and dust recipe

# 6.3.2
- Started work on rendering meshes, fluid and item all render no animation yet
- Added missing textures
- Added missing translations 
- Added missing sand dust to sand and dust to dust block recipes
- Redstone dust now comes from Dust Blocks
- Saplings Seeds item is now Sapling Bag

# 6.3.1
- Fixed Neo Version Range

# 6.3.0
- Updated to Minecraft 26.1.2

# 6.2.0
- Fixed progress bar position in strainer
- Fixed un filled progress bar texture being a pixel to small
- Added fluid tooltip to show current fluid inside the stainer 
- Strainer no longer processes when it cannot fit all outputs from current recipes
- Made fluid optional in strainer recipes, if no fluid is required the strainer will not match against fluids, if a fluid is inside teh strainer the recipe will still work as long as the required fluid is not specified
- Fixed recipes that should have had more than one result count having only one count
- Fixed not being able to shift right click from last slot
- Added FluidDropItem, theses are items that hold 250mb of the fluid they represent, these interact with any tank handlers as filled buckets would, consumed on use. Holding 4 of these and right-clicking will create a source block of the fluid. These items also have a tooltip explaining both features
- Added Water Drop
- Added Lava Drop
- Added Eroding Drop
- Added Purifying Drop
- Added reset recipe for the Strainer to clear internal tank
- Fixed more missing translations
- Added Ore Pieces Tag
- Added all meshes to strainers:meshes tag
- Added mesh tooltips showing tier
- Known issue drops producing sticks 
- Added some new recipes 

# 6.1.0
- Fixed Clicking on progress arrow in strainer not opening JEI category
- Added missing translations probably still some missing

# 6.0.0
- Updated to Minecraft 26.1.1
- Reduced mesh count to 8 tiers with a single mesh per tier
- Strainers now require a fluid in recipes, this fluid is not consumed but must be present in the strainer not in world
- Recipe now uses a min tier requirement this level is equivalent to the mesh tier tag
- Recipe now has additional_chance_per_tier this is added per additional level above the tier going over 1.0 will guarantee the output and then roles again with remaining chance
