Changelog BBL Strainer

# 6.7.1
- Increased the effects of fortune on ores 

# 6.7.0
- IMPORTANT - Hard Coded Ore Pieces will be being removed in future updates, craft them while you can!
- Added Ore Piece item. When loading a world, an ore piece for every ore type will be added 
- Added a new config inside config/bbl/strainers/ores.json, this is where you can set the color of the ore piece. By default, strainers supports vanilla, alltheores, mystical agriculture and a few other mods.
- Supported ores do not necessarily have recipes though!
- Mods that are not on the default ores list will still be added just using a default color instead
- Redone StrainerRecipeBuilder class for increased flexibility 
- Re-wrote StrainersProcessingRecipeProvider to use the new StrainerRecipeBuilder class for increased flexibility 
- Due to the above changes there may be some issues with recipes being missing / requiring incorrect tiers let me know !
- Higher tier resource chances have been increased, making rare ore more likely
- Added Seed Bag, works like the Sapling Bag but for seeds, seed recipes are now removed
- Added new config inside config/bbl/strainers/common.json, this contains options to both add and remove items from the seed bag and the sapling bag  
- Added Purified End Stone 
- Added End Stone recipe
- Added recipe support for Silent Gems, Forbidden Arcanus, Powah, Theurgy, Mystical Agriculture, Allthemodium and missing Alltheores 
- Recipes are subject to change

# 6.0.0

- Reduced mesh count to 8 tiers with a single mesh per tier
