Changelog BBL Strainer

# 6.5.2
- Gravel Pebbles no longer obtained with leaves, this is now stone pebble

# 6.5.1
- Added Sapling Bag from Mulch recipe

# 6.5.0
- Added Mulch, Purified Dirt, Purified Stone, Purified Soul Sand, Purified Soul Soil, Purified Gravel, Purified Sand, Purified Netherrack and Purified Dust Block
- Added Dirt Piles, can be crafted into Dirt Blocks
- Added Salty Water
- Added Depleted Drop, obtained when fluid drops are used 
- Fixed strainer recipes with a count in the item stack being ignored
- Leaf Piles can now be obtained when breaking any leaves with a stick
- BALANCE CHANGES, all of these changes are meant to reduce the resource generating power of strainers requiring extra steps and reducing chances this is WIP and maybe tweaked in the future
- Mulch is crafted with leaf piles
- Mulch can be strained to get Bone Meal, Stone Pebbles, Dirt Piles and Water Drops
- Water Drops removed from leaves
- Sapling Bags drop moved to leaves instead of dirt
- Most ores now come from purified blocks
- Tweaks to chances, reduced chances for higher end resource and additional chanced per mesh tier above from resource has dropped from 0.15 to 0.5
- Added a bunch of new recipes replacements as well as additions

- Meshes can be enchanted in the enchanting table

# 6.0.0
- Updated to Minecraft 26.1.1
- Reduced mesh count to 8 tiers with a single mesh per tier
- Strainers now require a fluid in recipes, this fluid is not consumed but must be present in the strainer not in world
- Recipe now uses a min tier requirement this level is equivalent to the mesh tier tag
- Recipe now has additional_chance_per_tier this is added per additional level above the tier going over 1.0 will guarantee the output and then roles again with remaining chance
